# Moltbot House Hunting

An Android application built with React Native (Expo) that helps you hunt for houses by reviewing Zillow links and gathering insights through an interactive agent (Moltbot).

## Features
- **WhatsApp Integration**: Share Zillow links directly from WhatsApp.
- **Interactive Review**: Review properties as cards and talk to Moltbot.
- **Learned Insights**: Moltbot learns your preferences over time.

## Installation
1. Clone the repo
2. Run `npm install`
3. Run `npx expo start`
